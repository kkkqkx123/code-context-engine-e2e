# tests

这里是 `cce-e2e-tests` 的集成测试入口目录。

## 分层

- `regression/`
  - 回归性测试。
  - 主要验证输出快照、格式化结果和固定 fixture 的稳定性。
- `workflow/`
  - 完整工作流测试。
  - 主要验证真实服务链路，但默认只启用 BM25 等不依赖 LLM 实际调用的路径。
- `benchmark/`
  - 索引效果对比说明。
  - 暂时只保留文档，不放性能测试实现。
- `fixtures/`
  - 集成测试专用输入数据。
  - 不与库根目录 `fixtures/` 混用。

## 约束

- 不要把新的回归测试继续放回根目录。
- 不要把工作流实现代码直接塞进 `tests/` 根下。
- 不要把 benchmark 当成性能测试目录使用。
